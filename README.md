🏠 Room Capture

Turn photographs of a room into a 3D model on your Mac.

Room Capture is a native macOS application built with SwiftUI and Apple’s Object Capture framework. It is designed to help users reconstruct 3D models from photographs.

🚧 Preview release: Room Capture is an early-stage project. Features and compatibility may change.

✨ Features

* 🖥️ Native macOS interface
* 📂 Select a folder containing photographs
* 🧊 Create 3D reconstructions using Apple’s Object Capture framework
* 📊 Monitor reconstruction progress
* 📝 View activity logs

💻 Download Room Capture

⬇️ Download Room Capture for macos-- https://github.com/armayunr-create/room-capture/releases/tag/VER-1.0.0_preview

1. Open the release page above.
2. Scroll down to Assets.
3. Download Room-Capture-macOS.dmg or Room-Capture-macOS.zip.
4. If you downloaded the DMG, open it and drag Room Capture.app into the Applications folder.
5. Open the app.

System compatibility

This is an early preview release. Compatibility has not been verified on every Mac. The app may require a compatible Mac and macOS version to use Apple’s Object Capture framework.

The app is not signed and notarized for public distribution, so macOS may display a security warning.
